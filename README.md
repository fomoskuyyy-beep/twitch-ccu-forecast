Quantile forecast of Grand Theft Auto VI's launch-day Twitch CCU: the program reads one case, takes hour 1's print and the release-day ratio curves of the case's comparable launches, and writes the 5/25/50/75/95 percentiles for hours 2 to 24, computed as hour-1 print times smoothed log-ratio quantiles.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out node main.ts
```
